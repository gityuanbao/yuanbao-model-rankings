## 一次生成，直接评分

1. 新开对话，选定明确型号。每次使用最高推理档位；无法设置最高档时使用默认档。记录实际档位并截图，不把不同厂商的最高档视为相同计算预算。
2. 发送一次[完整提示词](鹈鹕测试_统一提示词_v2.0.txt)。不追问、不重新生成、不修改原始代码。
3. 尽量关闭联网、代码执行和自动修复。无法关闭时注明；有工具、无工具和工具状态不明的结果分别标识，不把产品工具流程混作无工具单次生成。
4. 使用同一台电脑、同一浏览器观看原始 HTML：800 × 600，共 20 秒，结束停帧。可重播、暂停或慢看原作以核对动作，不能借此重新生成。
5. 测试者交回原作和测试信息，无需自己打分。AI 助手查看原作、逐项评分、记录扣分时间点、计算总分与档位；源宝复核作品与记录后发布。证据不足先标待核实，不猜分。

完整回答没有有效作品或原作无法运行，记作品失败 0 分。网络中断、权限或超时导致未收到完整回答，记请求未完成、待补测，不记 0 分。仅用 GIF 无法判断的内容须查看 HTML，转码或录制问题不能扣模型的分。

## 评分标准

16 项满分共 100 分。没做到给 0，做到一部分给一半，完整做到给满分：5 分项只能给 0 / 2.5 / 5；10 分项只能给 0 / 5 / 10。关键时间允许约 ±0.5 秒误差，事件顺序必须正确。简洁画法也可满分，不因个人配色偏好改动结构与动作分。

| 维度 | 检查什么 | 满分 |
|---|---|---:|
| 角色与结构 | 鹈鹕长嘴、喉囊、翅膀和双腿可辨认 | 5 |
| 角色与结构 | 自行车部件连接合理，骑姿成立 | 5 |
| 角色与结构 | 角色与橙色工具包的造型、颜色和位置关系稳定 | 5 |
| 骑行动作 | 两只脚持续跟随各自踏板 | 10 |
| 骑行动作 | 两个踏板围绕同一曲柄轴协调转动 | 5 |
| 骑行动作 | 车轮绕自己的轴旋转，方向与向右前进一致 | 5 |
| 骑行动作 | 踩踏、车轮与地面运动配合，停车不漂移 | 5 |
| 核心事件 | 红灯停、绿灯走，停车期间轮子、脚踏和前进背景也停止 | 10 |
| 核心事件 | 前后轮依次经过同一减速带，车、鸟和工具包合理起伏 | 10 |
| 核心事件 | 到站先停稳，再挥翅致意 | 10 |
| 时间与连续性 | 阶段顺序和时间正确，20 秒后停帧 | 5 |
| 时间与连续性 | 起步、减速和动作切换自然 | 5 |
| 时间与连续性 | 无闪烁、瞬移、部件脱离或明显不连续变形 | 5 |
| 运行与画面 | 原始 HTML 自动播放，使用 SVG，符合资源要求 | 5 |
| 运行与画面 | 800 × 600 内主体和事件清楚，不用字幕代替动作 | 5 |
| 运行与画面 | 配色和线条协调一致 | 5 |

脚偶尔脱离、事件只做了一部分、先后颠倒等，相关项给一半。三个核心事件得 0 才算未完成，得 5 算部分完成。

## 分数上限与档位

- 没有有效作品或原作无法运行：0 分。
- 只有静态画面：最高 39 分。
- 没有连续踩踏，或三个核心事件中有两项得 0 分：最高 59 分。
- “夯”必须同时达到总分 90、骑行动作 20 / 25、核心事件 25 / 30。未达到任一要求时最高 89 分。
- 多个限制取最低上限；最终分取合计分与上限中的较小值。同分并列，稳定展示顺序不代表额外的能力差距。

| 档位 | 最终分 |
|---|---|
| 夯 | 90–100 |
| 顶级 | 75 至不足 90 |
| 人上人 | 60 至不足 75 |
| NPC | 40 至不足 60 |
| 拉 | 0 至不足 40 |

本榜仅供娱乐，展示指定配置下的一次作品表现，不代表模型综合能力或绝对能力上限。不同规则版本不混排。
