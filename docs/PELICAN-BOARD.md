## 数据与历史

`src/data/pelican.json` 保留原作、测试记录和此前 AI 评分档案。首批人工评分位于 `data/pelican/manual-scores-2026-09-15.json`，按模型 ID 对应原作品，保存源 Excel 的 SHA-256、文件名、工作表、原表行号、五项得分及回传总分。`receivedAt` 为接收日期，不推断测试或评分日期。

`src/lib/pelican-manual.ts` 定义五项规则、Schema 和批次快照引用。构建时拒绝重复模型、空值、超出 0–2 的分数、非 0.5 步长、总分不一致或型号不对应。新增模型建立新的日期快照并追加引用，批次间拒绝重复模型 ID；调整已有分数时需明确新的生效快照，不覆盖历史成绩。不要直接修改本批原件或将历史 AI 分数换算为人工分。

2026-09-23 的三个 HTML 单独记录在 `data/pelican/html-submissions-2026-09-23.json`，由 `src/lib/pelican-html.ts` 校验，不虚构 GIF、AI 评分或测试平台、档位、日期。人工成绩记录在 `manual-scores-2026-09-23.json`：Claude Opus 5.5 为 8 分、GPT-6 Sol 为 7 分、GPT-6 Luna 为 4 分。源聊天表格转存为同目录 `manual-source-2026-09-23.md`；行号为该表的数据行（1–3），总分由五项相加，构建逐项对照源表。旧 14 份评分快照不改动。

当前页面经 `getPelicanShowcaseEntries()` 投影，下发型号、厂商、HTML 引用、材料说明与人工分；不下发历史 AI 评分、测试记录或 GIF 引用。`getPelicanShowcaseRows()` 筛选后按总分降序，排序不修改原提交数组。未评分作品放在独立待评分区，零分属于有效人工评分。

原件仍在 `public/pelican-originals/`：HTML 以 `.html.txt` 保存，下载时命名 `.html`；原有 ZIP 保留原始字节；本批新增 ZIP 由未改动的 HTML 原件打包。原 GIF、转换媒体、接收记录和初评记录均保留，不覆盖历史。新增作品时先核对型号和文件对应关系，不推测未知平台、档位或日期。

## 预览与测试

小窗、弹窗共用 `previewDocument()`：在原文解析前放置 CSP，iframe 仅启用脚本，不允许与父页同源访问。原作源码和 ZIP 下载不改字节。此约束用于本批已检查的自包含原作，不是任意恶意代码的安全证明。

使用 `npm test`、`npm run build`、`npm run validate:build` 检查数据、预览生命周期和链接。实际检查桌面/手机小窗、放大、关闭与焦点、加载失败、搜索、筛选、重置、分享和前进后退。GitHub Pages 子路径构建需要额外检查原作 URL。
