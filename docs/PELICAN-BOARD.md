## 数据与历史

`src/data/pelican.json` 保留原作、测试记录和此前评分档案。当前页面经 `getPelicanShowcaseEntries()` 投影，只下发型号、厂商、HTML 引用、材料说明及必要测试记录；不下发历史评分或 GIF 引用。当前页面使用 `getPelicanShowcaseRows()`，只筛选、不排名。历史排名计算函数保留供历史校验，不在当前页面调用。

原件仍在 `public/pelican-originals/`：HTML 以 `.html.txt` 保存，下载时命名 `.html`；ZIP 保留原始字节。原 GIF、转换媒体、接收记录和初评记录均保留，不覆盖历史。新增作品时先核对型号和文件对应关系，不推测未知平台、档位或日期。

## 预览与测试

小窗、弹窗共用 `previewDocument()`：在原文解析前放置 CSP，iframe 仅启用脚本，不允许与父页同源访问。原作源码和 ZIP 下载不改字节。此约束用于本批已检查的自包含原作，不是任意恶意代码的安全证明。

使用 `npm test`、`npm run build`、`npm run validate:build` 检查数据、预览生命周期和链接。实际检查桌面/手机小窗、放大、关闭与焦点、加载失败、搜索、筛选、重置、分享和前进后退。GitHub Pages 子路径构建需要额外检查原作 URL。

提示词仍使用[白猫骑车原句](鹈鹕测试_统一提示词_v3.0.txt)。[v3 手册](PELICAN-BENCHMARK-v3.md)里的评分规则目前仅作历史保留，暂停执行；不因记录里存在 AI 分数便重新定档，也不擅自替源宝决定名次。
