# 实现约定与验收计划

## 需求来源

空仓库初始仅含 `.git`，未提供根目录 PRD。本项目的 `PRD.md` 原样复制自用户附件《源宝 AI 模型价格榜 PRD v2.0》。附件提及的 DOCX 正式版未提供。本文只补充可调整的实现细节，不改写 PRD。

## 开发顺序

1. Astro + TypeScript 静态构建、厂商白名单和经过校验的 JSON 数据。
2. 首页冠军卡、输入 / 输出 / 标准任务排行榜。
3. 厂商、单价、上下文、状态、地区、使用场景筛选和 URL 状态。
4. 具有永久 URL 的模型详情、原币费率和计费依据。
5. 官方页面变更检查、人工审核流程及 GitHub Pages 工作流。

## PRD 未指定部分的实现约定

- 默认展示输入榜、日常聊天（输入 1,000 / 输出 1,000 Token），同时计算标准任务成本。长文本为 32,000 / 2,000，AI 编程为 8,000 / 2,000，均为比较预设而非行业标准。
- 名次采用竞赛排名：1、1、3。并列冠军全部可访问；排序次序只在并列时按稳定 ID 区分。
- 价格筛选为当前榜单度量的上限；上下文筛选为模型窗口下限。场景预设改变 Token 配比，使用场景筛选为编辑标注，不是能力评分。
- 地区表示该条费率的服务区域，不表示中国大陆网络可达性。
- 每个模型可以包含多档输入/输出长度费率。按完整请求选择阶梯，然后对全部 Token 应用该档单价。超过窗口或输出限制的请求不参与该次成本比较。
- 外币数据保留官方原币价格，人民币使用公开展示的固定参考汇率。参考汇率是可配置的估算参数，不宣称为实时外汇报价。
- 缓存只计算命中的输入读取价格，需设定命中比例；不包含首次缓存写入或存储费。Batch、低峰、促销需主动选择，不能自动叠加未经官方确认的优惠。促销须有有效期。
- 未核验的厂商只列入白名单，不伪造模型和价格。未知缓存价使用 null，绝不以 0 替代。
- 价格检查只生成候选差异报告和待审核 PR，不直接覆盖线上价格或最后核验日期。失败保留已有数据。

## 验收

- 自动测试覆盖百万 Token 换算、人民币折算、排序、并列、零价、阶梯边界、优惠开关、状态和 URL 恢复。
- 构建时校验白名单、唯一 ID、价格、来源域名、核验日期、费率阶梯和历史 URL。
- 浏览器验证筛选、场景、分享、详情跳转、返回、空状态、移动端以及子路径静态部署。
- 只有 GitHub 仓库启用 Pages / Actions 后，远端部署和定时检查才会执行；本地开发不等于已发布。
