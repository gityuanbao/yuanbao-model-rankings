请用代码制作一段“鹈鹕骑自行车”的二维矢量循环动画。

输出要求：
1. 只输出一个完整、可直接保存为 index.html 并在浏览器中打开的 HTML 文件，不要解释，也不要使用 Markdown 代码围栏。
2. 所有图形都使用内联 SVG 绘制；允许内联 CSS 和原生 JavaScript。不得使用 Canvas、外部库、联网资源、图片、视频、Base64 素材、Emoji 或图标字体来替代绘制。
3. 画面固定为 800 × 600 像素，SVG 的 viewBox 为“0 0 800 600”，页面无边距、无滚动条。背景简洁，主体完整且清晰可见。
4. 页面打开后自动播放。整个画面的动画以 6 秒为一个完整周期，无限循环，循环接缝自然，不需要点击任何按钮。

画面与动作要求：
1. 主角是一只从侧面可辨认的鹈鹕，具有明显的长嘴、嘴下的喉囊、鸟类身体、翅膀和两条腿。
2. 鹈鹕坐在一辆朝右的普通双轮自行车上。车轮、辐条、车架、前叉、车把、车座、曲柄与脚踏板应当清晰可辨，连接关系合理。
3. 鹈鹕的身体与车座保持接触，用翅膀扶住车把；两只脚分别跟随两个脚踏板连续踩踏，双腿自然屈伸，不能在空中乱蹬或穿过车架。
4. 曲柄持续转动，两个脚踏板保持相对位置；两个车轮围绕各自轮轴旋转，方向与向右骑行一致。
5. 可以让主体保持在画面中央，用地面或背景移动表达前进；不要求整辆车横穿画面。
6. 允许适度的身体起伏和装饰，但鹈鹕与自行车的基本结构必须保持稳定，不能脱节、闪烁、突然变形或移出画面。
7. 配色和造型风格自行决定。画面中不要出现模型名称、评分、标题或解释文字。
