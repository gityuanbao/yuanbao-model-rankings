请制作一段“鹈鹕送宝”的二维矢量动画：一只鹈鹕骑着自行车，带着橙色工具包，把工具送到社区小站。

【交付要求】
1. 输出一个完整 HTML 文件，保存后直接用浏览器打开即可播放。
2. 所有图形使用内联 SVG 绘制，允许内联 CSS 和原生 JavaScript。
3. 不使用外部库、联网资源、图片、视频、Emoji 或现成素材。
4. 画布为 800×600，采用侧面视角，主体和关键事件始终清晰可见。
5. 页面打开后自动播放，共 20 秒，结束后停在最后一帧；刷新可以重播。
6. 只输出完整 HTML 代码，不附解释。

【角色与结构】
主角具有清晰的鹈鹕长嘴、喉囊、翅膀和两条腿。
自行车有双轮、车架、前叉、车把、车座、曲柄与脚踏。
橙色工具包固定在后货架上，全程保持同一个外观。
骑行时身体坐在车座上，翅膀扶把，两只脚跟随各自踏板运动。
车轮绕自己的轮轴转动，方向与向右前进一致。
可以使用背景移动表现前进，但物体之间的相对运动必须合理。

【完整故事】
0–4 秒：正常骑行。
鹈鹕连续踩踏，自行车向右前进。

4–8 秒：等待红灯。
先减速，在第 5 秒前停到停止线前；保持停止至第 8 秒。
停车期间车轮、脚踏和表示前进的背景移动都停止。

8–14 秒：绿灯出发，经过减速带。
第 8 秒交通灯变绿，鹈鹕重新起步。
前后车轮依次经过同一条减速带，车身、鹈鹕和工具包随之小幅起伏。
不能让整个主体一起瞬间跳到另一处，也不能出现部件脱离。

14–20 秒：到站送达。
抵达社区小站，在第 18 秒前减速停稳。
停稳后再抬起一侧翅膀挥动致意，工具包仍留在后货架上。
最后保持在到站画面。

【画面要求】
风格与配色自行决定，简洁画法也可以。
角色、自行车和工具包在不同阶段保持一致。
不要用字幕描述代替实际动作。
不要出现模型名称、评分或解释性文字。
