## 发布内容

- 14 份可播放、暂停和全屏查看的作品录屏；页面不自动播放或预先下载所有视频。
- 每份作品有 11 个评分项、AI 初评理由、录屏时间点与测试记录。
- 画面项目齐全时显示 `/90`；Gemini 3.1 有一项构图待核实，只显示已完成 8/9 项，不补零、不折算。
- 原始 HTML / 完整代码缺失，网页与 SVG 两项均为 `null`；所有作品尚待源宝复核。正式总分、档位和前三名均未发布。
- 无正式成绩时，三张卡片展示作品数、待核验数和正式上榜数；五档说明折叠，档位排序暂不可用。补齐材料并完成复核后，系统按总分定档、同分并列。

评分标准为收到这批作品后补充，非事先登记的科学基准；评分前固定五类权重与 11 项口径，不按模型名或装饰多少评分，不为拉开差距改规则。GIF 仅支持画面初评，不代表模型综合能力。

## 材料与限制

原压缩包与 28 个附件保持不变。MiniMax 对应“千问.gif”，Qwen 对应“千问1.gif”，没有按文件名猜测型号。原始材料 SHA-256、作品映射、帧数、时长及转码文件校验值见 `data/pelican/submissions-2026-09-14.json`；逐项初评与截图转录见 `data/pelican/reviews-2026-09-14.json`。

14 个 GIF 合计 110,798,950 字节，网站视频和封面合计 10,143,891 字节。FFmpeg 7.1 转为 H.264 CRF 18 与 WebP 封面，等比缩放到最长边不超过 1280；逐个解码确认帧数一致，未裁切或改动作品内容。采用原帧间隔和时长。

型号按用户回传表标注；截图出现的平台与档位按可见标签转录，不声称已核实后台真实调用。GLM 实际题目以“做一个”开头，标记提示词差异；Qwen 的 0902、DeepSeek Pro 的 0813 后缀尚待证据。未从文件时间或规则要求推断测试日期、最高档设置、工具状态或是否首次生成。

后续需要每份原始 HTML / 完整回答，以及测试日期、平台、实际档位、工具状态、首次生成与未改代码确认。补齐后继续技术核验，由源宝复核评分。保留本次初评记录，不静默覆盖。
