# 模型厂商图形 Logo

使用 [Lobe Icons](https://github.com/lobehub/lobe-icons) 的品牌配色 SVG，优先选用彩色版本，保留原始图形，不使用文字占位、远程图床或字体图标。源文件、颜色处理和 Git Blob 校验值见 `sources.json`；完整 MIT 许可见 `LICENSE`。

展示保留各品牌配色，统一光学尺寸与圆角底座，不降低 Logo 的色彩透明度。品牌图形和商标属于相应权利人；本项目仅用于识别所比较的 API 服务。

页脚的 GitHub 与 B站图标同样来自 Lobe Icons，来源与校验值记录在 `sources.json` 的 `socialIcons` 中。
